## 📘 Description

This project includes a Java program `Kefel.java` that generates an x86-64 assembly file `kefel.s`.  
The generated assembly implements a multiplication function called `kefel` that multiplies a given number by **14** using only bitwise shift and addition operations, instead of the traditional `mul` instruction.

This method demonstrates low-level optimization by replacing costly multiplication with faster instructions.
